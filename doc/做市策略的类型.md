1. 纯固定 spread 做市
    围绕 mid price 固定挂 bid = mid - spread、ask = mid + spread。最简单，适合做 baseline，但容易被趋势打。
2. 库存 skew 做市
    和你现在类似，但可以更纯粹：库存多就压低 bid/ask 鼓励卖出，库存空就抬高 bid/ask 鼓励买回。可以不加 microprice/toxic 过滤。
3. Avellaneda-Stoikov / reservation price 做市
    用风险厌恶、波动率、剩余时间、库存推导 reservation price 和 optimal spread。比固定参数更理论化，适合单市场库存控制。
4. order book imbalance / microprice alpha 做市
    根据 best bid/ask size、深度 imbalance、microprice 偏离 mid 来偏移 fair price。你现在已经用了轻量版本，可以进一步扩大到多档 order book。
5. 趋势过滤型做市
    趋势向上时少挂 ask 或 ask 挂远，趋势向下时少挂 bid 或 bid 挂远。核心不是预测赚方向钱，而是避免逆势吃 toxic fill。
6. 波动 regime adaptive 做市
    低波动窄 spread、多成交；高波动宽 spread、少成交。你现在有 volatility_penalty_bps，可以扩成 regime 状态机。
7. 网格 / ladder 做市
    不只挂一档，而是在 mid 两侧挂多层订单。成交一层后补单，适合震荡行情，但趋势行情库存风险更大。
8. queue-position 做市
    重点不是 fair price，而是队列位置：什么时候 join best、什么时候 improve 1 tick、什么时候撤掉避免排队太后。对高频回测更贴近真实 maker 策略。
9. 单边 opportunistic maker
    只在有信号时挂一边，比如短期均值回归时只挂 bid 或 ask。它仍是 maker，但不强制双边中性。
10. maker + 本市场 taker 风控
    主体做 maker，库存超限或持仓时间过长时用同一市场 IOC/market 单减仓。你当前日终有强平，但可以扩成盘中 panic flatten。
